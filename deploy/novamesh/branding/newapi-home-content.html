快速提醒

Base URL
请填写到 /v1 这一层，不要填到根域名。
Windows 测试
PowerShell 建议优先使用 Invoke-RestMethod。
模型选择
拉不到模型列表时，先手动填写 gpt-5 或 gpt-5.4 测试。
客户入口
程序调用走 API 域名，额度与令牌查看走当前客户门户。
