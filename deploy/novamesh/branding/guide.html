NovaMesh AI 接入文档

这份文档给首次接入的开发者和客户使用。你会在这里看到基础地址、推荐模型、示例代码、门户入口，以及常见接入注意事项。

如果你是客户，建议先登录门户查看自己的令牌和额度；如果你是开发者，先调用 /v1/models 验证连通性。

API Base URL

https://api.model-port.xyz/v1

客户门户

https://panel.model-port.xyz

推荐起步模型

gpt-5、gpt-5.4、gpt-5-codex

接入前先确认

  1. 你已经拿到自己的 API Key，而不是管理后台密码。
  2. 客户端的 Base URL 必须填到 /v1 这一层，不要填到根域名，也不要填到具体接口路径。
  3. 如果你在 Windows PowerShell 里测试，优先用 Invoke-RestMethod，不要直接复用 Linux 的 curl -H 写法。
  4. 第一次联调建议先用 /v1/models，确认返回模型列表后再测对话接口。

接口 1：列出模型

PowerShell

Invoke-RestMethod `
  -Uri "https://api.model-port.xyz/v1/models" `
  -Headers @{ Authorization = "Bearer YOUR_API_KEY" }

Windows CMD

curl.exe https://api.model-port.xyz/v1/models ^
  -H "Authorization: Bearer YOUR_API_KEY"

Linux / macOS / Git Bash

curl https://api.model-port.xyz/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

Python

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.model-port.xyz/v1",
)

print(client.models.list())

接口 2：聊天补全

PowerShell

$headers = @{
  Authorization = "Bearer YOUR_API_KEY"
  "Content-Type" = "application/json"
}

$body = @{
  model = "gpt-5"
  messages = @(
    @{
      role = "user"
      content = "回复一句：测试成功"
    }
  )
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
  -Uri "https://api.model-port.xyz/v1/chat/completions" `
  -Method Post `
  -Headers $headers `
  -Body $body

Bash / Git Bash

curl https://api.model-port.xyz/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5","messages":[{"role":"user","content":"回复一句：测试成功"}]}'

Python

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.model-port.xyz/v1",
)

resp = client.chat.completions.create(
    model="gpt-5",
    messages=[{"role": "user", "content": "回复一句：测试成功"}],
)

print(resp.choices[0].message.content)

客户门户能做什么

  • 查看自己的剩余额度和余额。
  • 查看自己的令牌列表，并复制 API Key。
  • 查看历史调用记录和消费明细。
  • 查看你提供的模型说明和使用文档。

客户门户地址：https://panel.model-port.xyz

常见错误

  • 无效的令牌：先确认你复制的是 API Key，不是后台账户密码。
  • PowerShell 报 Headers 错：不要直接复用 Linux 的 curl 写法，改用上面的 PowerShell 示例。
  • 模型拉不出来：先手动填 gpt-5 或 gpt-5.4 测试，不要依赖客户端自动发现。
  • Base URL 不通：确认填的是 https://api.model-port.xyz/v1，不是根域名。

编辑器和客户端配置建议

如果你在 VS Code、OpenAI Compatible 客户端、脚本 SDK 中接入，优先使用以下模式：

  • Provider / API Type：OpenAI Compatible
  • Base URL：https://api.model-port.xyz/v1
  • Model：先用 gpt-5 或 gpt-5.4
  • API Key：使用你自己的客户令牌
